# 安装与打包

## 装技能（DSH）
```sh
dsh plugin --profile web add github:xiaotianya14/free-video-director
```

## 装原生面板（dsh-go App）
```sh
dsh plugin --profile web add ./dshgo-plugin
```

## 本地校验
```sh
node --check lib/index.js
node /root/.dsh/skills/dsh-go-plugin/kit/bin/check.mjs ./dshgo-plugin --load
```

## 打包
```sh
zip -r free-video-director-v0.0.1.zip . -x 'node_modules/*' '*.git/*'
```

## 发布两件套（下载校验）
```sh
sha256sum free-video-director-v0.0.1.zip > free-video-director-v0.0.1.zip.sha256
# 用户下载后：
sha256sum -c free-video-director-v0.0.1.zip.sha256
```
