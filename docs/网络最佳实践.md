# 网络最佳实践（联网补充）

> 这些内容来自公开的模型官方提示词指南与创作者经验，按本流程重新整理（非逐字转载）。引用见文末。

## 一、Seedance / 豆包官方进阶公式（推荐直接套）
> 精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件

官方强调模型把提示词拆成两层理解：
- **空间层**：画面里有什么（主体、场景、光、材质）
- **时间层**：事情随时间怎么变（动作顺序、镜头运动、转场）

所以好的提示词是「工程型指令」，不是文学描写：谁 → 在哪 → 做什么 → 镜头怎么动 → 按什么顺序发生。

## 二、写动作的四条硬规则（官方）
1. **肢体细化 + 程度量化**：写到手/腿/头/肩背，加幅度、速度、力度（缓慢抬手、快速转头、用力蹬地）
2. **优先低缓连续小动作**：避免狂奔、大跳、剧烈翻滚
3. **写动作过渡**：借转身惯性顺势抬手、从停顿自然过渡到举手
4. **情绪外化**：不要写「很悲伤」，写「低头、肩膀微颤、眼眶泛红、手指攥紧衣角」

## 三、一镜一运镜（官方）
一个镜头只指定 1 种运镜（中景缓慢推近 / 固定机位 / 平稳横移 / 环绕半圈）。
同时要求推拉摇移会显著增加画面不稳定。

## 四、分镜时序写法（官方）
用「镜头 1 / 镜头 2 / 镜头 3」按事件顺序写，每镜写：**运镜 + 主体动作表情 + 位置变化 + 音频**。
- 不要用秒数硬卡时长（模型对精确时间支持不稳定）
- 复杂叙事 = 分镜序列，而不是一句话塞满

## 五、约束词（必写，直接抄）
- 保持无字幕 / 避免生成任何文字或字幕
- 不要生成 Logo
- 不要生成水印
- 人物面部稳定不变形、动作自然流畅、无卡顿无闪烁

## 六、符号约定（官方建议，写复杂提示词时很有用）
| 信息类型 | 符号 | 示例 |
|---|---|---|
| 音乐 | （） | （背景播放快节奏摇滚乐） |
| 音效 | <> | <远处传来狗叫声> |
| 台词 | {} | {你好，世界} |
| 字幕 | 【】 | 【第一章：启程】 |

## 七、官方「常见问题」里最值钱的几条
| 现象 | 原因 | 解法 |
|---|---|---|
| 人物中途换脸 | 人脸参考图混用/占比小 | 单独大头照 + 全身照；素材靠前；**不要用三视图** |
| 视频里冒出字幕 | 模型自带倾向 | 提示词加「保持无字幕」；素材先去掉文字；横屏生成后再裁竖屏 |
| 画面有平台 Logo/水印 | 训练数据倾向 | 明确「不要生成水印/Logo」 |
| 风格漂移（2D 变真人） | 参考图写实 + 未强调风格 | 提示词写死「2D 日漫风格」；先把参考图转成目标风格 |
| 双胞胎/重复人物 | 主体定义不清 + 三视图 | 每个角色绑定参考图；末尾加「禁止同款分身/双胞胎」；单人独立照片 |
| 延长视频衔接跳变 | 帧不对齐 | 前段末尾删 6 帧、后段开头删 1 帧再拼 |
| 片尾咔哒噪音 | 音频截断 | 结尾做音量淡出（音量包络） |
| 中文多音字读错 | 模型发音 | 换成同音常用字（如「螭龙」→「吃龙」） |
| 参考角色超过 4 人 | 稳定性下降 | 分组生成图片（每组 ≤4 人），再图生视频 |
| 素材越多越好？ | 特征互相干扰 | 总计 4–5 个：角色 1–2 + 场景 1 + 运镜参考 1 + 音频 1 |

## 八、短视频钩子（创作者经验）
- 前 **3 秒**决定划不划走：用「具体且直接」的钩子（反常识陈述、结果前置、问题提问）
- 4–8 秒必须出现一次变化（切镜/推拉/信息更新），否则掉留存
- 结尾给 CTA 或回环到开头，提升完播与复看

## 九、和本技能怎么配合
1. 写提示词时套「一、进阶公式」+「五、约束词」
2. 多镜头按「四、分镜时序」写
3. 生成后按「七、常见问题」逐条自检（尤其字幕/logo/双胞胎/换脸）
4. 拼接按「七」的删帧法处理衔接；音频做淡出
5. 发布前按 `SKILL.md` 第 6 步质检清单过一遍
